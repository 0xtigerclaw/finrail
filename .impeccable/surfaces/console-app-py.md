# Surface brief: web console (console/app.py)

Scope: all console routes. Mode: Operate. Audience: a reviewer at a desk
verifying the trust story without credentials; job: run the demonstration
path and inspect verdicts, rules and the ledger. Constraints: server-rendered,
no build step, every page dispatches through the same capability path as the
CLI; content, routes and function unchanged from the incumbent console.

## Direction contract

THESIS: A calm, light operations console where verdicts are the loudest
thing on the page and chrome disappears into the task. It refuses the dark
terminal costume and the card-grid landing page.
OWN-WORLD: Paper-white ground, white surfaces with one elevation language
(soft shadow, no border-plus-shadow ghost), deep navy accent reserved for
primary actions and current selection, semantic state colours only for
verdicts. One sans family, fixed rem scale, tabular numerals for data.
STORY: The reviewer understands the rule (model suggests, code awards,
human releases), runs the planted-failure refusal, and can reconstruct any
judged call from the ledger, switching to the CLI whenever they prefer.
FIRST VIEWPORT: Light sidebar with brand and grouped navigation, a slim
status bar carrying the live engine pill, then the page heading and the
demonstration path. The primary action on each page sits in the first
viewport; terminal equivalents render as dark code wells, the one dark
element, because they are code.
FORM: Modern fintech light (owner-pinned via structured choice, 26 Oct
2026; user-pinned direction beats the roll). seed: none (unavailable)
FINISH: unreviewed and undocumented is unfinished; this build ends with
the finish review, the verdict, DESIGN.md, and every shipping raster
carrying its provenance
